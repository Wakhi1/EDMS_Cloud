# Generate a Report

The **Reports** section covers four built-in views:

| Report | What it shows |
|---|---|
| **Records by Status** | Count of records in each state (draft, pending approval, approved, rejected, declared final, archived, disposed) |
| **Records by Department** | Count of records owned by each department |
| **Claim Turnaround** | Average days from a workflow starting to its first decision, by month |
| **Audit Action Counts** | How many of each audit action (View, Download, Approve, Permission, ...) have been logged |

## Steps

1. Open **Reports** from the side navigation.
2. Choose a report tab.
3. Optionally filter by date range or department, where the report
   supports it.
4. Export to CSV if you need it outside the system (top-right of the
   report view).

## Who can see reports

Report access is governed by the same role × module permission matrix
as everything else — check **Permissions → Role × Module Matrix** if
a report tab is missing for your role. Internal Auditors and Approving
Managers have report access by default; Records Officers generally do
not.

## Try it in the Sandbox

Sandbox → **Reports** folder → any of **Records by Status**, **Records
by Department**, **Claim Turnaround**, **Audit Action Counts**.
